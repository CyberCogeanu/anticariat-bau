# E-Commerce & Service Integrations

Integrations with Romanian logistics and e-commerce infrastructure:
- Shopify REST / GraphQL webhooks (order creation, inventory change).
- Romanian courier shipping API (Fan Courier / Sameday).
- Romanian fiscal invoicing integration (SmartBill / Oblio).
- Cloudflare DNS automation (`manage_subdomain_dns.py`): CNAME setup and DNS propagation checks for custom subdomains pointing to Shopify.
- Shopify Domain Verifier (`verify_shopify_domain.py`): GraphQL domain attachment status and edge HTTPS connectivity probe.
